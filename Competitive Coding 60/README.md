# Assignment 60 - Logic Building

This assignment focuses on string-based logic building and problem solving using Java.

The programs are designed to analyze and process strings by comparing characters, checking character patterns, identifying duplicate characters, and calculating character frequencies.

## Objective
The main objective of this assignment is to:
* Improve logical and analytical thinking
* Understand string manipulation
* Process strings character by character
* Check whether a string is a palindrome
* Compare two strings to identify anagrams
* Check whether a string is a pangram
* Identify duplicate characters
* Calculate the frequency of each character
* Develop structured string-processing solutions

## Problems Covered
The assignment includes programs based on:
* Palindrome String
* Anagram Strings
* Pangram String
* Duplicate Characters
* Character Frequency

## Approach
Each problem is analyzed to understand the required string property or character operation.

The solution is implemented by processing the string character by character and applying suitable logic such as:
* Comparing characters from both ends of a string
* Comparing characters and their frequencies in two strings
* Checking whether all alphabets from a to z are present
* Finding characters that occur more than once
* Counting the frequency of each character

The programs use suitable loops, conditions, arrays, and functions to implement the required logic.

## 🧩 Problems Covered

This repository contains fully implemented Java solutions checking for the following numerical properties:

1. **Neon Number:** A number where the sum of the digits of its square equals the original number (e.g., $9 \rightarrow 9^2 = 81 \rightarrow 8 + 1 = 9$).
2. **Automorphic Number:** A number whose square ends in the exact same digits as the number itself (e.g., $5 \rightarrow 25$; $25 \rightarrow 625$).
3. **Spy Number:** A number where the sum of its individual digits is exactly equal to the product of its digits (e.g., $1124 \rightarrow 1+1+2+4 = 8$ and $1 \times 1 \times 2 \times 4 = 8$).
4. **Sunny Number:** A number where the immediate next integer ($N + 1$) is a perfect square (e.g., $3$ is sunny because $3 + 1 = 4$, which is $2^2$).
5. **Disarium Number:** A number where the sum of its digits raised to the power of their respective positional indexes equals the original number (e.g., $135 \rightarrow 1^1 + 3^2 + 5^3 = 1 + 9 + 125 = 135$).
6. **Trimorphic Number:** A number whose cube ends in the exact same digits as the number itself (e.g., $4 \rightarrow 4^3 = 64$; $24 \rightarrow 24^3 = 13824$).

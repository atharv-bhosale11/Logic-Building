# Assignment 58 - Logic Building (Java)

🚀 Welcome to Assignment 58! This repository focuses on strengthening logical reasoning and mathematical problem-solving skills using Java. The programs analyze various properties of numbers by extracting digits, calculating mathematical values, and implementing specific algorithmic conditions.

The primary goals of this assignment are to:
* Improve logical and analytical thinking.
* Understand diverse mathematical number properties.
* Practice digit-by-digit number processing techniques.
* Apply arithmetic operations dynamically in programming.
* Master the use of loops for repetitive calculations.
* Implement custom factorial and power calculation algorithms.
* Find proper divisors of a number efficiently.

## 🧩 Problems Covered

This assignment includes Java programs to check and validate the following special numbers:

1. **Strong Number:** A number whose sum of the factorial of its digits is equal to the original number (e.g., $145 = 1! + 4! + 5!$).
2. **Armstrong Number:** A number that is equal to the sum of its own digits each raised to the power of the number of digits (e.g., $153 = 1^3 + 5^3 + 3^3$).
3. **Perfect Number:** A positive integer that is equal to the sum of its positive proper divisors, excluding the number itself (e.g., $6 = 1 + 2 + 3$).
4. **Harshad Number:** An integer that is divisible by the sum of its digits (e.g., $18$ is divisible by $1 + 8 = 9$).
5. **Palindrome Number:** A number that remains the same when its digits are reversed (e.g., $121$).
